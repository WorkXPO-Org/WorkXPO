  ## Sobre o Projeto
  O **WorkXPO** é uma ponte entre o mundo acadêmico e o mercado corporativo. A plataforma foi idealizada para expor projetos acadêmicos inovadores, proporcionando a visibilidade necessária para atrair apoio institucional, infraestrutura e investimento financeiro.

WorkXPO is a bridge between the academic world and the corporate market. The platform was designed to showcase innovative academic projects, providing them with the visibility needed to attract institutional support, infrastructure, and financial investment.

## About the Project

Academic research often remains confined within university walls. **WorkXPO** (Work Exposition) changes this by offering a centralized hub where students can display their findings and companies can discover new talents and disruptive technologies. Our goal is to foster a collaborative ecosystem where science meets investment.

## Features

The platform is being built to provide experiences for both students and companies:

- **Project Creation:** Users can easily register their academic works.
- **Detailed Project Information:** Allows adding detailed data, such as research area, methodology, required support (financial/structural), and results.
- **Simplified User Registration:** Quick sign-up process for the students.
- **Authentication & Authorization:** Secure login system ensuring that users can only manage their own projects and data.
- **Responsive Showroom:** A modern, centralized interface to explore projects by category.

## Technologies

### Frontend
- **React.js**: For building a dynamic user interface.
- **TailwindCSS**: For modern, utility-first styling and responsive design.
